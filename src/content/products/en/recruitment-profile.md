## What is a Recruitment Profile?

The Recruitment Profile helps organisations recruit the right person, simply and effectively. Setting a requirements profile based on hard criteria is usually easy. Creating one that focuses on behaviour – and that also fits the organisation's values – is much harder.

The Recruitment Profile helps you build a shared picture of the role to be filled. The analysis produces a requirements profile with the soft skills that matter in the recruitment. It is shown in a clear graph that each candidate's Personal Profile can then be matched against.

## Where it is used

The Recruitment Profile is used effectively in recruitment, staff training, redeployment and personal development.
